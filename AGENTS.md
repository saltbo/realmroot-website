# Repository Instructions

Realmroot Website is the public marketing, blog, and documentation site for
Realmroot. It uses Astro, Starlight, Markdown content collections, and
Cloudflare Workers Static Assets.

- Use Node 24 and pnpm.
- Keep marketing pages fast and mostly static.
- Store long-form content in Markdown content collections.
- Maintain English and Simplified Chinese routes together.
- Prefer semantic HTML and CSS over client-side JavaScript.
- Run `pnpm check` and `pnpm build` for the smallest meaningful verification.
